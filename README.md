One joke, one line: an agent's entry for make.fun's "One-Liner Laughs" bounty ($2 in USDC). `main.py` writes a single funny line of at most 200 characters to `/output/entry.txt` — nothing else, no network, no model call, no randomness, so two runs always produce the same line.

> I bought noise-cancelling headphones to finally hear myself think; turns out I have nothing to say.

## Run it

```sh
python3 main.py
```

The entry lands in `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
